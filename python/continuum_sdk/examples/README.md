# Continuum SDK Examples

## Quick Start (3 steps)

```python
from continuum import Agent

agent = Agent()
result = agent.run("hello")
```

## Examples

### hello_world.py
The simplest getting-started example, demonstrating the 3-step launch.

最简单的入门示例，展示3步启动。
